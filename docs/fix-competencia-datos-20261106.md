# Corrección de lectura de Competencia

Se prepara la lectura de las fuentes por el servicio autenticado de Forms, manteniendo el procesamiento existente de filas. Pendiente comparar datos, filtros y permisos con la Base General antes de publicar.

## Validación y publicación

El 6 de noviembre se verificó con sesión corporativa la carga de 11/11 fuentes, indicadores, tabla y filtro de Cartagena en vista previa. El servicio autenticado fue publicado en Forms y la lectura corregida en GitHub Pages. En producción se verificaron 11/11 fuentes y 1.839 presencias; el aviso de fallo dejó de aparecer y la tabla cargó datos. Los valores mostrados dependen del corte y filtros seleccionados.
